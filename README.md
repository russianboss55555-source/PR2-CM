# ПР №2. Визуализатор зависимостей Cargo

Конфигурационное управление, вариант 22. Текущая версия реализует этап 1.
Программа проверяет пять параметров и выводит их в формате `ключ=значение`.
Проверка URL на этом этапе синтаксическая. Запросы к реестру, чтение графа
из файла и создание SVG относятся к следующим этапам.

## Запуск

Нужен Python 3.9 или новее. Прототип использует стандартную библиотеку.
Команды выполняются из корня репозитория. Параметр `--help` выводит справку.

| Параметр | Назначение |
| --- | --- |
| `--package` | Имя пакета Cargo. В тестовом режиме одна буква от A до Z. |
| `--source` | URL реестра по HTTP(S) или путь к существующему тестовому файлу. |
| `--test-mode` | Переключает источник на локальный файл. По умолчанию выключен. |
| `--output` | Имя файла результата с расширением `.svg`. |
| `--ascii-tree` | Включает режим вывода ASCII-дерева. По умолчанию выключен. |

У переключателей есть явные формы `--no-test-mode` и `--no-ascii-tree`.

```bat
run.bat --package serde --source https://index.crates.io --output graph.svg
run.bat --package A --source tests/fixtures/simple.json --test-mode --output graph.svg --ascii-tree
```

В PowerShell запускайте скрипт как `./run.bat`. В Linux или macOS замените
`run.bat` на `python3 src/main.py`. Отдельная сборка прототипа не нужна.

## Проверка ошибок

В первом примере запуска по очереди замените один аргумент на значение
из таблицы. Программа выведет сообщение об ошибке и завершится с кодом 2.

| Что заменить | Пример ошибки |
| --- | --- |
| Имя пакета | `--package "bad name"` |
| Источник | `--source invalid-url` |
| Режим работы с файлом | `--test-mode=maybe` |
| Имя SVG | `--output graph.png` |
| Режим ASCII-дерева | `--ascii-tree=maybe` |

Для проверки отсутствующего файла во втором примере укажите
`--source tests/fixtures/missing.json`.

```bat
py -3 -m unittest discover -s tests -v
```

Для Linux или macOS используйте `python3 -m unittest discover -s tests -v`.
